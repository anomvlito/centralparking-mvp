# Centro documental de Central Parking

Fuente de verdad de producto y trazabilidad para los repositorios
`centralparking-mvp` y `adyac-camaras-frontend`.

## Estructura

- `historias-usuario/`: HUs numeradas globalmente por actor.
- `features/`: capacidades agrupadas por `Etapa` del Project 4.
- `decisiones/`: ADRs y decisiones técnicas/producto.
- `guias/`: controles transversales y regresión.
- `plantillas/`: formatos mínimos para documentos nuevos.
- `github/`: auditorías y planes de sincronización con GitHub.

Una HU accionable no está completa hasta vincular Markdown, feature, issue del
repo `anomvlito/centralparking-mvp` e item del Project 4.
